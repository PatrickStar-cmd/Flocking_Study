## 编译

使用支持 Windows 中文字体的 XeLaTeX，在本目录执行两次，建议将中间文件输出至单独构建目录：

```powershell
xelatex -interaction=nonstopmode -halt-on-error -jobname=论文草稿_KF预测补偿_v4 论文初稿_KF预测补偿_v4.tex
```

正文引用图均包含在 `figures/v4/`。独立编译用于检查依赖与页数，不覆盖审核后的 PDF。
