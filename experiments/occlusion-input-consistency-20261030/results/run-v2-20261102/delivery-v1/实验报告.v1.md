# 遮挡后初始社会输入与最终运动一致性：实验报告.v1

采用v2三因素输入与原始无补偿神经场；主实验500种子，历史对照各100种子，共14000条轨迹。每条遮挡后6000步，主终点为末1000步逐时min(GO,LO)的均值。
区间采用10000次独立种子整体重采样；同一种子下20个遮挡条件一起抽取。精确零输入单列，正输入按0.012固定分箱。

## 三因素输入S与总强度A

相同轨迹、相同五折种子分组、同为二次回归的探索性留组预测RMSE：S=0.16595，A=0.16585。更小的RMSE表示在该固定描述模型下更好的留种子预测。完整散点和条件均值对照见analysis-v2/social_input_and_strength_control.png。本批单边强度固定，A与邻居数成正比；S进一步记录遮挡时相对方位。
