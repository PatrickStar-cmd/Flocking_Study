# P2 冻结设计（运行前）

## Material Passport

任务：计划书 P2，固定轨迹上的开环方位估计诊断。类型：探索性开发集。来源：`Hao_L@c0ab184` 的 P1 Fresh 轨迹及同版本仿真器。授权：用户要求 Codex 与 AGY 完成 P2 并上传 Hao_L。只读保护：原始模型、所有既有代码和结果。当前任务仅新增 P2 目录。

## 问题与设计

所有方法面对同一真实轨迹、同一带噪观测和同一缺失掩码，估计结果不反馈物理运动。比较 Hold（最后原始观测）、KF-CV、KF-GM。只研究方位及角速度，不估计二维位置，不推断闭环收益。

5个开发种子沿用 P1：2026110101–2026110105；这些种子不是新的独立验证集。N=20，神经元100，k=15，原始等权输入，其余物理参数继承 P1 diagnosticConfig。每个观察者循环 ID 的前7条边为人工缺失候选（共140条有向边），其余8条仍参与参考物理轨迹。每个种子有一条已有 Fresh 原始轨迹和一条新受控转向 Fresh 轨迹，共10条物理记录。

- S：在无外部转向轨迹的候选起点1201:20:1681上，按后续120步的真实方位变化率均方根选最小值，平局取最早。只能称为本开发轨迹池内的慢变化层，不预先声称高 GO 或全局稳定直行。
- V：同一候选集合和同一评分选最大值，平局取最早。选择不读取估计器结果。
- T：受控转向，起点1401。全部20个个体接受旋转的异中心刺激核；刺激持续400步，幅度0.06，角速率0.02 rad/模型时间，基准方向为同种子 Fresh 在1401步更新前的实际航向。刺激目标在第t步是基准方向+0.02*(t-1401+1)*dt。沿用原有受控转向接口，不改变物理代码。

转向组与原始 Fresh 使用相同初始物理/神经状态及逐点相同的传感噪声；检查1400步完整状态前缀一致。转向是否实际改变运动，报告实际航向与方位变化，不仅报告接口开启。

S/V/T各5条片段；D=20和120步（6/36模型时间），预窗口200步，恢复400步。总共30个回放条件，每个条件同时运行3种估计器。S/V来自同一物理轨迹，不能算成10个独立种子或相互独立的样本。每次回放从物理记录第1步开始预热，人工缺失期之外全新鲜观测。

dt=0.3，测量标准差0.01rad，R=1e-4rad²；CV q=1e-4，GM q=1e-5、tau=10，均为仓库已有默认值。二者过程噪声参数数值不同且模型不同，比较是默认配置整体对比，不能把差异单独归因于 GM 结构。本轮不扫描或选择 Q。若出现失配，只建议后续开发校准。

门限：age>120模型时间或P_theta>1rad²。先保存不截断的滤波预测，再单独计算部署门限的生效比例和有效子集误差；门限不能通过删去高误差时间点美化主要结果。Hold仅使用age门限，其协方差/覆盖率/NIS不存在。新鲜观测步骤不受P门限阻断。
