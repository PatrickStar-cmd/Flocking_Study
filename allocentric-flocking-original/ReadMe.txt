Matlab codes for 'Allocentric Flocking' by Mohammad Salahshour and Iain D. Couzin.

The code to produce the raw data for individual and collective motion in the Neural Field Model are provided in this folder. Three main scripts can be used to run the three functions for individual motion, collective motion (allocentric and egocentric) and collective motion with switch between allocentric and egocentric. The codes produces a figure and the data for the trajectory of the agent(s). The expected run time of the demo is less than 10 minutes. The code needs a running MATLAB license to be used. Further documentation is provided in the functions.
