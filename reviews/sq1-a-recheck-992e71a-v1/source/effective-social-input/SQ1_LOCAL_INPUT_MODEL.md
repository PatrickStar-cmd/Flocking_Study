# 科学问题一 A：社会输入与局部机制模型

## 1. 研究对象与信息边界

A 只建模一个 focal agent 接收到的方位社会输入，以及该输入驱动的单体环形神经场响应。输入来自已选中的邻居方位 `theta_j` 和非负权重 `w_j`；局部回放不读取二维邻居位置、距离、隐藏目标状态、KF 状态或群体运动状态。

因此，本文档描述的是输入层和局部神经响应模型。群体位置更新、选邻策略、遮挡分支和批量统计由后续群体仿真负责。

## 2. 社会输入模型

对神经场方位网格 `alpha_m = 2*pi*m/M`，单个时刻的社会输入为


\[
I(\alpha_m,t)=\sum_j w_j(t)\exp\!\left[-\frac{d_c(\alpha_m,\theta_j(t))^2}{2\sigma^2}\right].
\]

其中 \(d_c(a,b)=\min\{|a-b|,2\pi-|a-b|\}\) 是圆周距离，\(\sigma\) 是方位调谐宽度。离散输入积分使用

\[
\operatorname{Mass}(t)=\frac{2\pi}{M}\sum_m I(\alpha_m,t).
\]

输入总权重和为 \(A(t)=\sum_j w_j(t)\)。当 \(A(t)>0\) 时，归一化方位结构为 \(p_j=w_j/A\)；当 \(A(t)=0\) 时不定义方位分布，代码将方向性指标置为零并标记 `hasDirection=false`。

输入强度与方位结构分开记录：

- 强度：`A`、`Mass`、`fieldPeak`；
- 一阶方位矩：\(z_1=\sum_j p_j e^{\mathrm{i}\theta_j}\)；
- 二阶方位矩：\(z_2=\sum_j p_j e^{2\mathrm{i}\theta_j}\)；
- 角度覆盖：\(1-\operatorname{maxGap}/(2\pi)\)；
- 结构熵：\(-\sum_j p_j\log p_j\)。

`z1` 反映圆周合矢量集中程度，`z2` 用于识别双峰结构。多峰或近均匀输入不能只用一个主方向解释。

## 3. 局部神经场更新

回放使用与现有环形神经场一致的离散更新：

\[
u(t+1)=u(t)+\Delta t\left[-u(t)+\frac{W\tanh(\beta u(t))}{M}-\gamma+I(t)\right].
\]

神经输出为 \(r=\max\{\tanh(\beta u),0\}\)。解码方向使用

\[
\psi(t)=\operatorname{atan2}\!\left(\sum_m r_m\sin\alpha_m,\sum_m r_m\cos\alpha_m\right).
\]

`bumpConcentration` 是解码向量模长除以非负神经输出总量，用于描述局部活动是否形成明确方向性峰。

## 4. E1 确定性对照

E1 使用 `M=100`、`dt=0.3`、`120` 步、`sigma=0.4`、零神经初态；不使用随机种子。

1. **强度缩放**：固定方位结构，权重总和取 `0.5/1/2`，检验 `Mass` 和场峰值随强度变化。
2. **方位结构**：固定总权重，比较集中、双峰和八方位分散结构，检验 `z1/z2`、最大方位空隙和神经场形状。
3. **标签拆分等价性**：把同一方位的一个权重拆成多个标签；完整输入场和神经状态应逐点一致。
4. **fresh/hold-last**：方位随时间变化与保持第 40 步方位的局部对照，只描述时间输入模式，不代表群体预测收益。

## 5. 与后续群体仿真的接口

群体仿真应同时记录 `k_selected`、`k_fresh`、`k_active`、`A`、`Mass`、`z1/z2` 和最大方位空隙。`fixed-total` 只用于拆分总强度和方位结构的机制效应，不应直接解释为自然传感器或控制律。

本模型没有距离权重、遮挡、预测或数据关联错误；这些机制需要在群体实验中单独引入并单独审计。

## 6. 证据边界

E1 是确定性局部机制的探索性开发证据。它可以验证输入公式、指标定义和神经场接口，不能证明群体层面的可靠阈值、闭环稳定性、碰撞安全或预测方法收益。
