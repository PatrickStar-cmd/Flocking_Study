# 时序分析：先读这里

已完成 240 个规范运行的 11 组配对分析，输出 11 张时间过程图（PNG/SVG）和窗口统计。完整数字和各图见 [REPORT.md](REPORT.md)。

## 本轮增加了什么信息

### 1. 输入制度的差异不只出现在一个总均值里

以 k=8 为例，fixed-total 相对 original 的 GO 平均差，在 6001–7000 步为 +0.3782，在 7001–8000 步为 +0.3901。两个窗口都显示同方向的有序性差异；两窗口差异的变化为 +0.0119，逐项95%区间 [−0.0450,+0.0752]，没有清楚证据说明后半比前半更强。

这支持将“输入幅值制度”保留为重要机制对照，但不证明每个种子始终改善，也不证明达到稳态。

[查看 k=8 输入制度时间图](03_strength_k8.png)。蓝色处理为固定总幅值 C06，橙色参照为原始制度 C11。

### 2. 总均值会掩盖距离效应随时间的改变

在 k=8、固定总幅值下，分散/balanced 相对随机选邻的归一化对距差：

| 时间窗口 | 平均差 | 逐项95%区间 | 描述 |
|---|---:|---|---|
| 6001–7000 | +0.05392 | [+0.00476,+0.10236] | 分散策略平均更松散 |
| 7001–8000 | −0.01446 | [−0.05785,+0.02928] | 均值略紧凑，但方向不明确 |
| 后半减前半 | −0.06838 | [−0.10440,−0.03459] | 当前数据出现向更紧凑方向变化的线索 |

因此原主窗平均差 +0.01973、区间跨零，不应解释为“整个过程都没有区别”。同样不能把后半均值变负解读为“分散策略最终更好”。这是一条待验证的时间变化线索；多重比较未校正。

该策略 GO 在两半均低于随机，平均差分别 −0.16184、−0.13809。这再次说明有序性与凝聚性要分开报告。

[查看分散与随机的时间图](10_policy_balanced.png)。蓝色处理为分散 C02，橙色参照为随机 C06。

### 3. 邻居数比较也依赖观察窗口

固定总幅值时，k=12 相对 k=8 的对距差从前半 +0.01216 变为后半 −0.03051。两个窗口各自的区间均跨零，后半减前半为 −0.04267，逐项区间 [−0.07992,−0.00574]。可报告时间变化线索，不能据此宣布 k=12 更好或选择最优 k。

[查看 k=12 与 k=8 的时间图](07_count_12_8.png)。蓝色处理 C07 为 k=12，橙色参照 C06 为 k=8。
