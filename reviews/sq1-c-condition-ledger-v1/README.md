## 3. 条件规范化规则

按以下顺序处理，原文件保持不变：

1. 480行按`strengthMode,selectionPolicy,k,seed`忽略experiment标签归并为280个键，重复行所有指标完全相同。
2. `angle-dispersed`与`balanced`在本次提交中代码相同、结果相同，因此作为同一策略；减少20个重复键。
3. k=19时两种幅值制度均选择全部邻居、每边幅值一致，作为`full-equivalent/all`；再减少20个重复键。
4. 得到240个键、12个条件。代表行取原CSV最早出现的对应行，并记录全部映射关系；未按性能挑选代表。

规范条件为：一个全邻居条件、原始制度下k=2/4/8/12四个random条件，以及fixed-total下四个random条件和k=8的balanced、angle-concentrated、nearest三个条件。

`canonical_policy`和`canonical_strength`为分析用标签；保留的`selectionPolicy/strengthMode/experiment`是代表原行的标签。不要混用这两套字段统计样本量。等价关系仅对当前提交、等权及当前配置有效；算法修改或距离权重变化后不能直接沿用。

## 4. 种子台账的边界

- 台账基于已提交CSV的明确`seed/randomSeed/random_seed`列，不依据文件名或“nSeeds”等计数字段推测种子。
- 多个分支拥有同一个路径及相同blob时只扫描一次；同一个实验的汇总、分种子导出和再分析表可能重复记录，均标注不得累加为独立试验。
- “已用”表示已有结果或分析中出现，不等价于每个文件都重新模拟；具体训练、标定、评估用途须结合原目录文档确认。
- 未扫描到的种子，尤其142–200和230以后的编号，**不被本报告认证为未使用**。未推送、被忽略、仅MAT记录、JSON-only记录及成员个人实验仍可能使用这些编号。
- 未来独立验证由C维护预留台账，A/B补充自己的未共享记录；三人确认并冻结方案后再选种子。本轮未预留任何新种子。
- 同一个数字seed不保证不同程序生成相同轨迹；也不能以改换seed数字代替真实独立初始化和数据隔离。
