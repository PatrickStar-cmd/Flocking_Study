## B的实现要求

控制器先按固定ID、可用观测和合法缓存构造激活边，再以有限方位、非负权重、该个体真实神经网格alpha_i计算输入。不要用局部回放的零起点网格代替alpha_i；不要把隐藏NaN或不可读真值传入参考函数。固定边排序，保持T=0与共同前缀的同一运算路径。

| A字段 | 四分支导出/解释 |
|---|---|
| totalWeight | A=sum(weights)，与inputMass分开 |
| activeCount | k_active；不能替代k_selected或k_fresh |
| angularEntropy | weightEntropy=-sum(p log p)，仅标签权重熵；若保留旧名须标legacy |
| z1/z2及其模 | 保存实部/虚部、R1/R2，辅助区分集中、双峰与覆盖 |
| hasDirection | 仅作legacy诊断；正式direction_defined=(A>0且R1>1e-8) |
| maxAngularGap | 非空沿用公式；无激活正权重时导出NA，不能把函数的2pi哨兵解释为实测覆盖 |

没有正权重激活边时，适配器直接生成长度M的零场：A/Mass/峰值/k_active=0，z1/z2数值占位为0，no_input=true，direction_defined=false，方向/角差/最大空隙/weightEntropy为NA。归一化不可用标记按主协议设置。数值占位不表示观测到真实零集中度。不要依赖参考函数接受空数组。

神经解码与输入主方向分别标记。记录非负神经活动的质量及归一化一阶模bumpConcentration；质量>0且bumpConcentration>1e-8才有decoded_direction_defined=true，否则分析用神经角和角差为NA。已有模型运动规则及其原始解码值单独保留，不因这个分析标记擅自改变运动轨迹。

hold必须在j=1…200执行fresh规则，缓存j=200步初最后合法观测，j=201开始使用缓存；不复用A的全程常角hold示例。恢复时按各分支自身当前几何重新获取观测。

## G15参考适配验收

B提交以下测试日志，C独立复核，A核对公式：

1. 普通、跨±pi、平移神经网格场景，适配器输入场与固定A参考及独立标量公式相符；容差绝对1e-12、相对1e-10。
2. 同一方位权重w拆成同方位w/2两标签，输入场与神经更新等价；计数变化不冒充独立邻居数量效应。
3. 对向双峰R1约0时方向无效、R2可高；四同向与四均匀方向权重熵相等；不能据熵声称角结构相同。
4. 空集合、全零权重、全部隐藏、无缓存hold的字段/零场符合上表；隐藏NaN在接口前被过滤，且不读取隐藏真值。
5. 低神经一阶模的有限atan2值标记为无有效方向；分析标记不改变原运动更新。
