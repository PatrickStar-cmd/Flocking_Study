# 高频方位预测：运行前设计

目的：判断粗采样失败是否仍出现在实际dt=.3观测下，避免无依据地继续群体T扫描。

四条全邻居等权N20参考轨迹，种子138–141，原神经参数8000步，每步保存位置，不按GO筛选。遮挡只在线下屏蔽预测阶段观测，不改变参考运动。这是离线预测实验，不是遮挡闭环实验。

138–139训练选q，140–141仅测试；各20条固定循环有向边、三个截止位置索引6001/6801/7601（对应模型时间1800/2040/2280）。每个截止点使用此前含本点200次观测；从下一时刻起只预测，不更新。人工高斯噪声std=.01 rad，R=1e-4，所有方法/q共享同一观测流。候选q=1e-8/1e-6/1e-4，按训练集各跨度等权MSE选取，不用评估结果选参。

预测10/34/100/200/400步，即3/10.2/30/60/120模型时间。最后值保持使用相同最后观测。报告圆周方位RMSE、名义95%覆盖、区间覆盖整圆的比例、周期最短像跳变、每个评估种子的MSE差；不把120条边-窗口误差当120个独立种子。两种子只支持诊断，不能作统计认证。历史NIS仅为观测段诊断，不是鲁棒门限。

每条参考轨迹单独保存，分析复用文件不重跑。完整q网格误差保存在errors.csv，summary.csv仅为训练选q后的评估结果。若预测仍差或覆盖不合理，先检查运动假设、截止门限和边界；不得只扩大Q改善覆盖后宣称均值预测改善。

## 已完成结果

四条参考轨迹已保存，3600条唯一预测记录完整；Python标准库独立复算测试RMSE，与MATLAB输出一致。训练选q=1e-4（候选上界），三候选训练MSE为1.0988/.8929/.8443；不能据此声称找到了全局最优q。没有更新线上默认参数。

结论：不能将粗采样的问题全部归因于采样不足。高频输入下短期KF仍更差；中期平均改善具有种子依赖。T3没有任何周期像跳变，因此短期退化不能归咎于这一边界效应。去掉含跳变的预测窗口（仅事后诊断，不改变主统计）后，T10.2/30的KF误差.3339/.6727，对照.3991/.7192，但仍不证明闭环收益。

T60/120的95%区间已覆盖整圆，100%覆盖不具有方向分辨意义。这里测的是未截止的预测器；实际神经场还有maxVariance=1和maxAge=120门限，不能把这些离线长时预测直接当作仍在使用的输入。当前不能宣称协方差已经校准，亦不能声称T容忍界限已测得。

下一工作：复用已保存高频轨迹，检查短期大误差对应的距离、方位机动和角速度估计，比较常角速度与带角速度衰减的候选模型。模型修改只在训练种子上决定，140–141从现在起属于已查看数据，后续确认必须用新种子。不要为了得到更好的覆盖率而单独扩大方差。维持现有T扫描暂停状态。
