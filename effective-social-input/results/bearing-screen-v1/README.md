结论：当前粗采样常角速度模型没有稳定优于保持，协方差明显低估误差。不能把它作为已校准预测器直接投入正式T扫描。60/120的微小总体均值优势不是可靠收益证据。训练估计tau=sigma/median(abs(theta_dot))约87.31，仅是粗采样尺度，不能直接决定正式T网格。

机制限制：真实群体方位有机动，周期最短像可发生跳变，30时间单位观测间隔可能角度混叠；当前滤波器是局部圆周单峰近似。不能因此否定更高频观测或其他状态模型。

下一步需要少量高时间分辨率参考观测，而不是再次全参数扫描：明确观测采样周期，保存每步方位/距离和神经状态；分开训练/评估种子，用相同噪声检验保持与预测、误差与协方差。优先检查模型失配和周期跳变，不通过单纯扩大方差声称预测改善。高频验证后再实现完整检查点恢复与四分支T=0回归。
