# 挑战2：知情领航转向与连续观测缺失，三种子开发实验

日期：2026-10-14。证据等级：**探索性开发集评估**。
本批实际实现并运行了3个开发种子，包含任务有效性检查、失败设置保留、
冻结后的KF/hold比较、原始轨迹、时间曲线及独立统计复核。

## 主要发现

1. **无遮挡可以完成方向调整。** 最终设置中，3个种子的跟随者末30步
   平均方向为44.26°、51.65°、50.53°，平均个体指令误差为6.10°、6.93°、
   6.94°；领航者误差约2.55°--3.16°。无遮挡任务检查3/3通过。
2. **遮挡切断了全部领航信息，出现退化，但强度尚不充分。** T=18时，
   drop相对fresh的遮挡期跟随者误差增加2.70°、3.41°、2.42°，均值2.84°。
   原先声明的3°开发检查只在1/3种子上通过，没有放宽。T=6和10.2时平均
   增加0.69°、1.34°。不能据此宣称已经建立普遍有效的遮挡失效场景。
3. **KF在本开发场景下优于hold。** T=18时，KF-mean相对hold的隐藏边方位
   误差、社会输入标量误差、GO参考偏差和遮挡后固定近邻距离参考偏差均较小，
   这几项在3个逐种子配对中方向一致。KF-mean和协方差卷积版本十分接近，
   当前数据不足以确认协方差卷积带来额外闭环收益。
4. **长期逐个体检查发现不利结果。** T=18、种子2026101401中，KF-mean与
   KF-uncertainty各有1名跟随者末30步平均误差117.18°，明显偏离群体；同一
   种子的fresh/hold最大个体误差约14.52°/14.90°。不能把早期平均改善外推为
   长期逐个体优势。完整轨迹与该不利结果一并保留，没有删去该对象或种子。

## 最终冻结设置

- 代码基线：YCwork，ff12161788f3ea079c25c011927b32f47e7a1cc4。
  本次仅新增独立脚本和结果，未提交、未推送。source哈希见metadata/audit。
- N=20，3个领航者、17个跟随者；M=100；dt=.3；L=1000；beta=1000；
  速度尺度=.05；sigma=.4；单边强度h0=.012；每个对象k=15。
- 固定有向拓扑：每个跟随者观测3个领航者和沿环12个跟随者；每个领航者
  观测另外2个领航者和13个跟随者。初始为构造的有序神经活动和带扰动网格，
  不代表从随机无序状态自组织成功。
- NumPy PCG64种子2026101401--2026101403；串行1worker；无种子排除。
  与历史MATLAB mt19937ar同编号并不构成相同随机流。
- 初始100步静态前向线索；之后3名领航者接受相同的余弦方向输入，幅值.32、
  角速度.025 rad/模型时间，转45°后保持。**正余弦项激励目标侧，负项抑制
  相反侧，是领航者专用的外部任务驱动变体**；不是把负权重加入跟随者社会输入。
  跟随者不读取任务指令，神经场和KF均无隐藏真值访问。
- 转向100步（30个模型时间）后开始遮挡；所有方法共800步、相同指令和
  噪声流。此时跟随者指令误差仍约46°--48°，未趋于新方向一致。
- 全部51条“跟随者观测领航者”边屏蔽，其他边保留：300条选定边中249条
  新鲜可见。跟随者环仍连通，没有未遮挡领航信息的绕行通路。原始20个对象
  均继续运动且都参与评价。**这是有向观测连续缺失，尚非真实障碍物几何遮挡。**
- 主比较：fresh、drop、drop-normalized、hold、KF-mean、KF-uncertainty。
  另有相同静态线索的straight fresh/drop对照。
- KF：q=1e-4，R=1e-4，P0=diag(R,1)，噪声标准差.01rad，年龄门限120，
  方差门限1rad²；未根据本批KF效果调参。所有测试时长中51条隐藏边均保持
  激活，所以hold与KF的方位误差按相同边/时间窗评价。

注意：45°指令约在遮挡开始后1.42个模型时间结束，但领航者相对方位仍继续
变化，跟随者仍在调整。本批主要验证**已观测转向后的跟随追赶过渡过程**，
不能称为全遮挡期间持续未知转向的预测验证。转向指令及未来信息未提供给KF。

## 指标口径

- GO使用20个实际区间速度单位向量；LO使用自身+5个当前周期最近邻。
- fixed5_distance：在遮挡前物理状态冻结5近邻身份，之后跟踪这100条有向
  距离的均值；同时保存当前最近邻、平均对距、领航--跟随距离和最小距离。
- 转向误差：17个跟随者相对共同指令的个体圆周绝对误差均值。另报领航者
  指令误差、实际平均方向、平均速度和运动比例。
- v4经验量：S_i=sum_j w_ij exp(cos(theta_ij-phi_i)-1)，A_i=sum_j w_ij，
  C_i=S_i/A_i。图中是17个跟随者的均值，外部领航任务线索不计入S/A/C。
  drop/hold/KF-mean使用各自实际输入中心；协方差版本对经验核取相同
  wrapped-normal后验的期望。S_memory单独统计隐藏领航者的缓存/预测贡献。
- S_oracle采用**各候选分支自身同一时刻的真实几何和朝向**离线计算，
  S_abs_error=mean_i|S_i-S_oracle,i|。不能将其当作同一fresh几何上的
  完整输入场误差，也不能把该标量等同于完整方向场。S对左右方位对称。
- S在区间起点计算；GO/LO/距离/转向误差在区间速度解码与位置更新后计算，
  CSV共同time表示该步区间结束时刻。
- KF名义95%区间在T=18的全部隐藏边--时间点上的开发覆盖率约98.3%；
  这不是跨场景校准结论、鲁棒性或安全证明。

- `reference/`：调用现有MATLAB接口生成12步神经场和跨角度分支/连续缺失
  的滤波参考；最大轨迹数值差5.7e-14、神经状态差3.9e-16，滤波状态差
  1.4e-15以内。现有`testOcclusionPrediction`回归通过。
- 契约检查通过：隐藏真值改变不影响控制输入、完整51边屏蔽、首次无观测不
  注入、方差/年龄门控、恢复观测重新激活、圆周卷积质量保持、经验S后验
  Fourier计算与独立高斯数值积分吻合。
- 所有运行均断言共同前缀；各方法T=0全轨迹、末神经状态完全相同。
  最终批次还保存并核对遮挡前完整物理/神经/滤波检查点。
- 独立校验脚本不导入仿真器，从NPZ原始状态用math定义复算3660个状态样本
  的GO/LO/固定近邻距离/转向误差/真值S；最大误差3.6e-14。
  另复核54组共同前缀与噪声、9个遮挡期配对均值、54条唯一汇总记录。
  6个前置gate批次也全部通过独立复核。
- `paired-effects.csv`使用5000次种子配对bootstrap，种子2026101400，
  保留所有3个配对值。n=3、经历开发选择、未作多重比较修正，区间只能作为
  探索性描述，不用于确认性显著性或可靠性主张。
- 无遮挡任务3/3的95% Wilson区间约[0.439,1]；T=18强遮挡检查1/3约
  [0.061,0.792]。没有证明95%可靠性。
- 元数据包含Python/NumPy版本、随机流、参数、基线提交和开跑时源文件哈希；

## 限制与建议

长期末30步群体平均转向误差如下；它们与早期的参考偏差不是同一评价窗口。

| 方法，T=18 | 种子2026101401 | 种子2026101402 | 种子2026101403 |
|---|---:|---:|---:|
| fresh | 6.097° | 6.930° | 6.938° |
| hold | 8.302° | 8.293° | 11.851° |
| KF-mean | 10.839° | 5.360° | 7.296° |
| KF-uncertainty | 12.966° | 10.268° | 10.964° |

KF-uncertainty的末段群体平均误差在2/3种子上高于hold；KF-mean在1/3高于hold。
种子2026101401的两种KF存在117.18°个体偏离，种子2026101402的KF-uncertainty
最大个体误差约74.82°。额外尾部检查为事后描述性诊断，30°/90°计数仅帮助
定位问题，不替换原任务门槛，也不构成新的通过定义。

本实验支持在特定构造状态、拓扑和转向追赶任务中观察输入缺失及KF外推的
有限窗口作用。无遮挡本身也会空间展开：末段平均对距约29--38、领航--跟随
距离约69--82，不能声称维持紧凑编队。没有碰撞避免、二维位置恢复、真实
障碍物遮挡或闭环稳定性保证。
