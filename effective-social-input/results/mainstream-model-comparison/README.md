# Mainstream model comparison

Paired exploratory comparison, seeds 101--105, N=20, T=30. All models start from the same allocentric-neural-field checkpoint. Vicsek uses neighbor headings; Boids and the Olfati--Saber-type potential-consensus baseline use relative positions and headings. They therefore have richer observations than the proposed bearing-only method. Parameters are representative and not independently optimized; conclusions should emphasize sensing-efficiency and robustness patterns, not a universal algorithm ranking.
