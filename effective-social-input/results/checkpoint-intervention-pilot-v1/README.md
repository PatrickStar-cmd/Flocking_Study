# 完整检查点遮挡干预：探索性结果

运行前设计见相邻的 `../checkpoint-intervention-pilot-v1.DESIGN.md`。本实验首次从同一位置、航向、神经活动、神经元全局偏好角和随机观测流分叉。`testCheckpointFork` 已验证 `T=0` 逐字段相同、遮挡前共同轨迹相同和固定配置重复运行相同。

## 配置与证据边界

N=20，k=15，固定循环编号目标，隐藏 7/15 条输入，等权 `a(r)=1`，原始单边增益，方位噪声标准差 0.01 rad。`T={3,10.2,30}`；比较无遮挡 control、删除隐藏输入 none 和保持最后方位 hold。种子 136–137 都是已经使用过的种子，因此结果仅用于机制 pilot，不是阈值或显著性证据。

两个检查点结束前 200 步平均 GO 分别为 0.3635 和 0.3373；分支全程无遮挡 GO 均值为 0.5654 和 0.5818。这里没有按高 GO 筛选检查点，避免用成功终点制造干预差异；代价是初始状态异质且样本很少。

| 3 | hold | 0.00003 | 0.000000 | 0.000010 | 0 | 8 |
| 10.2 | delete | 0.00197 | 0.000208 | 0.001752 | -0.08422 | 8 |

| 30 | hold | 0.01921 | 0.000411 | 0.005368 | 0 | 8 |

对距已除以 L；本实验 L=1000，因此 T=30 后固定窗口的 0.010064 与 0.005368 分别约为 10.06 和 5.37 个实际距离单位。删除分支输入质量下降 0.08422，约为无遮挡 0.18048 的 46.7%，与删除 7/15 条等权边一致；hold 保留输入质量，但方向随观测年龄变旧。

## 判断

最稳定的探索性信号是群体分散：遮挡后对距增量随 T 增长，hold 在三个 T 上都小于删除，T=30 时约减半。GO 不满足单调性，且 hold 在 T=30 的遮挡期 GO 损失反而大于删除；这说明“保留输入总量”和“注入过期方向”有不同后果，不能只用输入质量或 GO 单指标定义有效下限。

当前两种子不足以估计 T 下限，也不能证明 hold 优于删除。下一步应先冻结正式响应：以相对无遮挡的对距增长或失效风险为主，GO/LO 为并列结果；然后用未使用种子扩大 paired checkpoint 实验，并加入被遮挡目标方位结构分层。预测器仍不进入该扫描。
