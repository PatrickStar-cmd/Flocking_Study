# 2026-09-09 时间序列验证：运行前冻结方案

种子 101–130，N=20，默认神经参数（8000 步，burn-in 6000，dt=0.3），无预测、理想方位观测。六个条件：全邻居原始强度、零输入、随机固定总输入 k=7/15、平衡固定总输入 k=15、随机原始强度 k=15。共180次仿真，按种子配对初态。

主要输出为连续描述量：GO/LO/距离均值、逐点成功占比、按实际时长加权的100/300步块均值达标占比、失效段长度和删失标志。块长30/90模型时间单位；末尾200步计60单位，不丢弃。阈值固定为旧1–50种子均值分位数，应用于块均值/瞬时值是探索性诊断，不能自动解释为高极化或安全任务要求。90%/95%二元阈值不作为本轮主结论，不按策略排序更改规则。

本轮是未使用种子的机制/方法验证，不是95%可靠输入下限的确认性试验。30种子不足以认证95%可靠性。分析以种子为独立单位，块不能作为独立重复。基线失败允许如实报告；不为提高通过率放宽定义。

每个seed-condition MAT持久保存完整result（含逐步timeSeries、config及稀疏位置轨迹）、两种block表、连续summary及阈值；每次完成后原子改名。每次恢复检查complete标志。软件版本及参数保存在metadata.mat；代码SHA256与日志同目录保存。旧结果不改写。测试入口testBlockTimeMetrics，运行入口runTimeSeriesValidation。
