## 几何定义

MATLAB round与Python对齐为sign(x)*floor(abs(x)+0.5)，特别检验±0.5和±1.5。140边顺序为观察者1..20，每观察者循环偏移1..7。逐时刻switch用min-image相对位移任一分量变化>500定义，同时保留未折叠坐标镜像编号变动，不将坐标普通wrap误报为物理方位突跳。

每edge/window使用200步历史加D步遮挡。优先级：G-switch（遮挡期至少一次switch）>G-close（无遮挡期switch但遮挡期r<5）>G-clean（历史+遮挡无switch且无near_aliasing，遮挡r>=5且半场余量>=10）>G-ambiguous（其余，包括仅历史switch、近边界或记录不足）。逐点near_aliasing=abs(wrap(diff theta))>=.9pi，near_range=r<5，near_half_box=min(abs(abs(dmin)-500))<10。连续角速度仅在前后两点非近距离且邻接switch标志不存在时用圆周差分；第一步无差分。清洁窗口的连续速率以这些有效差分的RMS表征。

开发集所有预定义base/turn ×25候选起点1201:20:1681 ×2D ×140边均保留。只对G-clean的连续速率做一次全局三分位，合并两个D和base/turn，不使用预测结果；rate<=q1为slow，q1<rate<=q2为mid，其余fast。验证仅使用冻结切点。G0旧种子仅审计，不用于选择正式切点或q。
