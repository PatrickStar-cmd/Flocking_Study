# 遮挡干预：停止泛化扫描后的执行方案

状态更新（2026-09-09）：衰减角速度候选已在高频轨迹上完成开发评估，但因 T=3 退化和协方差失配未通过接入门槛。正式预测分支继续暂停。第2步检查点分叉仍需实现，首轮只运行无遮挡、删除和 hold；这能估计新鲜社会输入中断的因果效应，但不能回答预测收益。

执行更新：完整检查点分叉及两种子 pilot 已完成，见 `results/checkpoint-intervention-pilot-v1/README.md`。状态恢复和共同前缀均已通过测试。对距响应显示可用效应，但 GO 非单调；正式扩展前需冻结以 paired 对距/失效风险为主的响应，并把方位结构作为预先定义的分层因素。

目的：在同一集体运动状态下，测量遮挡造成的偏离，以及预测是否优于最后值保持。没有通过下述准备门槛前不运行大规模T扫描。

## 1. 已有轨迹上的预测筛查

screenBearingPrediction读取已保存的全邻居轨迹，不生成新群体仿真。轨迹采样间隔30模型时间，不能插值后声称得到dt=.3真值。固定20条循环编号有向边、两次历史截止点，只用截止前观测更新滤波；噪声标准差.01 rad，以种子固定噪声。101–115仅用于从q={1e-8,1e-6,1e-4}中按总体方位MSE选q；116–130仅评估预测30/60/120时间后的误差、覆盖率及逐种子配对改善数。保持分支保留最后一次带噪观测。覆盖率只描述圆周最短误差落入区间的比例，大方差接近整圆时不能解释为精确预测。

这是旧轨迹上的探索性离线筛查，不是新种子确认，不证明闭环收益。若误差差于保持或不确定性失配，先改预测模型，不更改群体成功定义。粗采样有角速度混叠和周期最短像切换限制；筛查通过也必须在真实步长下验证。

## 2. 检查点分叉（待实现）

首轮固定N20、k15、固定邻居身份、原始增益、已声明的距离权重。必须先验证该新拓扑下参考运动，不能把random选邻的结果当作固定拓扑基线。保存位置、朝向、神经场、环形坐标、滤波状态、邻居身份和随机流状态。不能只传initialXY重新随机初始化神经场和滤波器。

每个检查点分四分支：无遮挡、删除、保持、卡尔曼卷积。对象在检查点依据当时可用观测选择，遮挡人数取floor(k/2)=7（记录7/15，不写50%）。四分支及全部T共用对象集合。初版按固定身份选取；近/远或方位选择留作单独因素。

无遮挡对照也使用相同观测和权重制度，不允许控制输入访问隐藏真值。每分支共用固定长度预生成观测噪声流，避免根据遮挡数量消耗不同随机数。T=0各模式应逐步完全一致。

## 3. T及响应冻结

利用训练参考轨迹的方位变化率估算tau=sigma/median(abs(theta_dot))。先检查其分布及相对评价时长再冻结T；不根据哪个时长产生所需差异来调网格。全部分支比较相同总时长H=max(T)+恢复窗口。

主响应为每种子相对无遮挡的GO平均损失、距离平均增加；分别报告遮挡期、固定的遮挡后窗口，以及全长H。不要把不同长度积分直接比较为相同效应。辅助报告LO、方位误差、预测方差、输入质量和恢复曲线。恢复时间若需要阈值须另行预先指定，未恢复为删失。

统计单位为独立种子/预先选定的检查点；同种子多个窗口不得增加独立样本数。报告全部分支和配对区间；卡尔曼不优于保持是允许的结果。若仅筛选有序检查点，记录筛选规则与排除比例，只称维持能力。
