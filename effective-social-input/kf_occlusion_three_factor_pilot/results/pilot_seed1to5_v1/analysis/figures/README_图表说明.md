# 图表阅读顺序

所有图均可由包根目录analyze_results.py从原始结果重建，提供PNG和PDF。曲线点是5个seed均值，扫描图的浅色散点是各seed值，不是误差条。各扫描横轴为三个离散水平，连线仅方便阅读。

1. `same_state_L2`：同一fresh轨迹状态上的输入场误差，越低越接近fresh。左图改变遮挡数量，中图改变隐藏方位结构，右图改变完整观测总权重。中心条件KF约0.021、hold约0.055。
2. `closed_loop_recovery100`：恢复后100步的平均对距增量，定义为branch−fresh并除以1000。零线是fresh，负值表示更紧凑，不能直接解释成更优。
3. `absolute_pair_deviation100`：平均绝对对距偏离，作为补充描述，不替换预定有符号主指标。
4. `bearing_prediction_RMSE`：离线方位预测误差，单位弧度。各seed先求RMSE，再对5个seed平均；与汇总全部边的总体RMSE不是同一个统计量。
5. `center_condition_time_curves`：中心条件的逐步同状态输入误差和闭环对距增量。阴影为5个seed最小到最大范围，不是置信区间；灰色背景为缺失期。
6. `R_sensitivity_by_seed`：中心条件不同假定R的方位误差和95%区间覆盖。能看出seed2失配；不能只用总体平均掩盖它。
7. `realized_hidden_R1`：方位结构实际产生的隐藏R1。每个数据点先对一个seed的20个体取均值；盒图仅描述5个值。集中/分散是相对最大/最小R1，不是固定绝对方向。

当前观察：数量增加时KF的平均输入误差上升，但闭环对距增量并不单调；方位结构改变后的KF平均输入误差存在差异，但5个seed不足以推导普适排序；高A0下KF误差较小，但A0改变了整个预热轨迹，不能称为“单纯增加强度必然提升KF”。

所有图只适用于本次5个开发seed及人工方位缺失协议，未包含KF-uncertainty、真实几何遮挡或完整三因素交互。
