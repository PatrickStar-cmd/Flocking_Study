## 一、研究定位与证据结构

研究问题：在少数具有目标方向提示的领航者引导群体运动时，跟随者暂时无法观测领航者的方位，利用合法历史信息进行预测能否改善方向一致性和任务跟随？目标方向按既定曲线由0°变到45°，作为固定任务条件，不单独研究转向对方法收益的因果作用。

应用原型是导航信息不对称的无人机群：少数个体拥有任务方向，其余个体通过局部观测响应；视觉短时丢失或方位信息暂时不可用，会中断关键引导信息。这里仍为抽象运动模型与人工观测缺测，不把它直接称为建筑物几何遮挡仿真或真实飞行验证。

建议论文围绕一个限定场景建立证据，主要评价KF是否在领航者观测缺失时有效。证据分为：原协议核心场景复刻、独立样本主比较、遮挡时长与时机边界、较大群体扩展。增加运行数用于检验效果是否可重复、是否具有任务价值。

核心结论目前均为待检验：

| 拟研究的主张 | 对应证据 | 状态 |
|---|---|---|
| 领航者方位缺测时KF相对hold提高GO | 独立种子、原T=18场景中的配对比较 | 待实验 |
| 改善发生在跟随者，且有助于跟上任务方向 | 跟随者GO、个体目标方向误差 | 待实验 |
| 不确定性输入在一定缺测长度下有额外价值 | KF-uncertainty与KF-mean、门控和误差诊断 | 待实验 |
| 效果不限于一个缺测长度和20个体 | 固定参数的T扫描、N=40/60扩展 | 待实验 |

## 四、主实验：7方法×30种子，210条运行

原六方法全部保留，并增加一个简单趋势外推基线，区分“预测优于保持”和“卡尔曼处理本身有价值”。

| 方法 | 用途 |
|---|---|
| Fresh | 全程含噪完整观测参考，不是假设无噪声真值驱动 |
| Drop | 无补偿，检查丢失信息的影响 |
| Drop-normalized | 控制可见输入系数总和的变化 |
| Hold | 主要比较对象，使用最后含噪观测 |
| Linear-trend | 简单有限历史趋势预测，作为额外强于零阶保持的基线 |
| KF-mean | 当前核心预测方法 |
| KF-uncertainty | 原协议的圆周分布卷积输入 |

### Linear-trend的固定定义

对每条边，只缓存最近10次连续合法观测与时间戳；以最短圆周差展开角度，按真实时间做最小二乘直线拟合得到斜率。缺测时从最后一次含噪观测出发，以拟合斜率继续外推并取模；不足2次观测时退化为hold。缺测期间不把自己的预测写回拟合历史，恢复后重新建立连续合法观测历史。age上限120，与hold相同；不额外引入依赖真实值的截断或角速度信息。新鲜边同样直接使用当前观测。

窗口10是建议默认值，不宣称最优。若在开发集比较5/10/20后选择，必须记录选择规则，给予其他方法同样的开发机会，且冻结后不按评估结果更换窗口。无估计方差的基线不强加KF方差门控；一旦门控实际起作用，要记录其区别，不能把全部效应都归因于滤波。

### 主指标与主要对比

保持原协议全部20个体GO作为唯一主要效果指标，主要窗口为遮挡60步。种子s的主效应为：

    Delta_GO_s = mean_occlusion(GO_KFmean - GO_Hold)

主假设比较只用KF-mean对Hold，不在看到数据后改为表现更好的KF版本或时间窗口。若论文最终将KF-uncertainty定义为主要提出方法，应在冻结前将其设为主要对比对象，不能事后互换。

必须同时保存以下预先定义的次指标：

1. 跟随者GO_F：17个跟随者单位速度向量之和的模/17，静止者置零。回答改善是否发生在跟随者。
2. 跟随者目标方向误差：沿用原协议E_turn字段和公式，即17个个体对目标方向的绝对角差均值，单位deg。它评价任务跟随，不用于转向/直行机制比较。GO高但跟错方向不能称为任务性能全面改善。
3. D_fixed5及相对fresh的逐步绝对偏差：反映局部队形关系保持。另报全群平均对距，避免将局部指标等同整体凝聚性。
4. 每步最小机间距、最近邻距离：只作几何诊断；没有机体尺寸与安全阈值，不宣称防碰撞。
5. 原S及S_abs_error；隐藏边方位误差、门控数量和P11。S较大不自动等于更好，它包含幅值和方向因素。
6. 领航者目标误差、领航者与跟随者平均方向差、跟随者至领航者平均距离。若群体未实际跟随，要如实解释。

所有指标保留遮挡窗口、恢复后100步、终末30步及完整800步曲线。状态/输入时刻约定与原协议一致。补充指标不用于随意寻找“显著”结果。

## 五、稳健性与时序边界

### 5.1 遮挡时长扫描：新增360条

T取6、18、30模型时间，即20、60、100步。T=18复用主实验。开始时刻仍为第201步，其他参数不变。Fresh与T无关，每个种子沿用同一条Fresh轨迹，不重复计算或计样本。

T=6和30分别运行其余6个方法，新增2×6×30=360条。每种T的遮挡窗口按各自长度计算，恢复100步从自己的恢复时刻开始。终末窗口保持第771—800步。保留全800步曲线，同时画绝对时刻对齐图及遮挡相对时刻图，避免把不同恢复阶段混在一起比较。

这一步用于回答预测收益随信息过期时间如何变化；允许长遮挡下失效。门控是否触发必须由真实记录决定，不能因为设置了方差门控就声称门控带来收益。

### 5.2 较早发生的遮挡：新增90条

固定T=18，将缺测改为第141—200步，即0起始140<=n<200；任务提示保持第101步开始。遮挡起点之前目标已转约17.19°，遮挡结束时目标约42.97°，因此大部分遮挡发生在指令仍持续变化的阶段。

运行Hold、KF-mean、KF-uncertainty各30条；Fresh继续复用主实验。新增90条。此条件与原第201步开始的遮挡形成事先确定的时序对照，仅检查补偿性能对遮挡起点是否敏感。

早期条件的相对标签为(n+1-140)*.3，冻结5邻居在第141次更新前重新按其共同状态选定；不能复用主场景第201步的冻结邻居。恢复100步是第201—300步。

## 六、群体规模扩展：新增180条

主实验的效应重复性主要靠独立种子，不是简单增加飞机数量。另运行N=40、60，保持领航者比例15%，即6＋34和9＋51；T=18、q/R、h0、任务与总步数不变。每规模先比较Fresh、Hold、KF-mean，30×2×3=180条。

为了不把个体数量扩大等同社会输入强度扩大，每个对象仍有15条输入，每个跟随者仍观察3个领航者＋12个跟随者，社会输入系数总和仍.18。

可执行的扩展图定义（下标0起始）：

- 领航者数L=.15N，跟随者数F=N-L。
- 跟随者f观察领航者(f+r) mod L，r=0,1,2，以及跟随者(f+r) mod F，r=1,...,12。
- 领航者l观察领航者(l+1) mod L、(l+2) mod L，以及跟随者(13*l+r) mod F，r=0,...,12。
- 缺测集合是所有被选中的“跟随者观察领航者”边，分别102、153条；其余边不变。检查图连通、无自环、行度数和领航者覆盖，记录实际矩阵。

以上是规模扩展图，不能声称与原N20拓扑完全同构；N20主实验仍严格使用原图。三个规模只作各自内部方法配对比较，不把跨规模的绝对GO差全归因于N。

扩展初态采用相同间隔、扩展面积的编队：领航者l放在(492,500+8*(l-(L-1)/2))；跟随者采用行数r=ceil(sqrt(F))的网格，f的位置为(480-8*floor(f/r),500+8*((f mod r)-(r-1)/2))。沿用坐标.4噪声、航向.03噪声及原神经初始化。名义局部间隔保持8，不把更多飞机挤入原来的同一小块区域。

这并非严格相同密度/拓扑的理论极限测试，布局与图分配随N改变；结果只支持所定义的大群体扩展。各规模保存实际初始密度与距离。若扩展场景Fresh任务跟随失败，保留结果，解释为该配置不适用，不删除种子或事后重新摆队形。

## 八、统计分析与结论规则

1. 先每种子算窗口平均，再对30个配对差汇总。报告均值、标准差、中位数、95%区间和30个原值；正/负/近零数量只是描述，不代替效应量。
2. 主比较预设为T18、原时序、N20、全群GO、KF-mean对Hold。用配对均值差及95%区间表达；可采用配对t区间/检验，并用10000次种子整组bootstrap（固定分析种子20261014）作敏感性分析，偏态和异常情况如实展示。时间点不能当独立样本。
3. 以原量纲差Delta_GO为主要效应量，例如+.01是GO增加.01，即1个百分点，不是自动等于相对提高1%。不以单个p<.05替代实际意义。可把.01设为讨论用参考幅度，但缺乏平台任务依据时不能称其为通用工程合格线；正式最小有意义效应必须在揭盲前由组内说明理由。
4. 若主均值差区间整体大于0，且跟随者GO与任务误差结果一致，可支持该场景下的平均GO改善；若差很小，应称小幅改善。若区间跨0，就写证据不足。只有小部分种子有利时，报告不稳定性。
5. KF-uncertainty对KF-mean、KF对Linear-trend，以及其他方法的比较为预设次比较；若进行显著性宣称，按同一比较族使用Holm校正。不得把显著的次比较升级成原主假设。
6. 时长/时机/规模结果作为扩展证据，报告全部条件效应及种子配对值。若正式检验多个扩展条件，预先定义比较族并校正，不能挑其中一个有利条件代表全部。复用相同种子的分析需保留重复测量结构。
7. 声称“不牺牲凝聚性/任务误差”需要预先给出可接受退化界限，并作相应非劣效评估；“差异不显著”不能证明没有损害。若暂无合理界限，就仅报告实际变化，不写保证性结论。
8. 可使用原工程检查描述Fresh是否成功转向、Drop是否明显受影响，但不按该检查剔除种子。方向均值不适定、静止比例、门控及数值失败全部记录。算法数值失败不默默排除，也不擅自填GO=0；报告失败率和有效样本，定位后用明确新版进行全量重跑。

本版本仅研究既定领航任务下的补偿效果。可以据结果描述有效条件与失效边界；不据此声称收益由转向机制导致、只有转向时有效，或相对直行具有更大优势。

## 九、额外消融：按论文真正主张选择

以下不计入858条核心方案，不能在没有运行时写成已有证据。

- 若声称“不确定性卷积是创新”：至少在T18/30增加“同样方差门控、只用均值核”的对照（主KF-mean已提供），记录实际P11与剔除比例；若门控活跃，再分别去掉方差门控和去掉卷积，避免混淆两者贡献。无门控情况下的方差范围也要保留。
- 若声称“噪声下稳健”：增加噪声标准差0、.03，保持主滤波器R=.0001作为失配鲁棒性实验；若另让R跟随噪声方差，应明确标为已知噪声/重新匹配条件，不和固定参数结果混称。各新噪声用相同基础标准正态数组缩放。
- 若声称“关键领航信息比普通同数量缺失更重要”：每个跟随者改为屏蔽3个跟随者邻居，保持缺失51条；掩码要按预设规则并做多次重复，不能以单个随机集合代表全部。该对照改变信息来源，需记录初始方位结构差异。
- 若声称“真实遮挡有效”：需要另建视场/遮挡几何或实验数据，不把人工NaN掩码直接改称几何遮挡。运动平台验证作为后续工作也可以，但须限定论文的仿真范围。
- 若论文主张普遍领先于现有预测控制：还需文献检索选择同信息条件的相关方法；本方案的7种方法不足以预先宣称SOTA。简单预测基线用于评估KF相对保持/趋势估计的增益。
