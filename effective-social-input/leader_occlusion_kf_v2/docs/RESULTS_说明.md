# 领航者方位缺测实验：实际结果

按v2方案完整执行858条科学运行：18条原开发复刻＋840条新评估。评估种子2026101501—2026101530，共30个独立种子；各方法/窗口/规模属于配对条件，不是858个独立随机样本。没有无转向机制对照。代码未据评估结果调参、换种子或改变窗口。

**主比较：支持该场景下KF-mean的平均GO改善。遮挡60步内GO(KF-mean)−GO(Hold)均值为+0.005851，配对t的95%区间[+0.005483, +0.006219]；bootstrap区间[+0.005502, +0.006200]。30种子中30个正差、0个负差。**

GO取值0—1，差+.01表示增加1个百分点，不代表相对提升1%。种子正差计数仅用1e-10数值容差，不是实际效益阈值。统计证据与实际幅度须分别判断。

## 可用于论文的有边界表述

在所定义的领航者目标方向引导与方位缺测场景中，KF-mean相对保持最后观测的遮挡期全群GO配对差为+0.005851（95%区间+0.005483至+0.006219）。该结果来自30组初态与观测噪声重复。是否同时改善跟随者任务响应，以及在不同遮挡长度、时机和群体规模下保持收益，应按上述实测表分别陈述。

不研究“收益由转向机制造成”的因果结论。本轮是近似有序初态、固定图、人工方位缺测的抽象仿真；没有真实几何障碍、平台飞行、避碰或闭环稳定性证明。30种子仅覆盖规定的扰动分布。多实验数量不能替代论文的算法/任务贡献。
