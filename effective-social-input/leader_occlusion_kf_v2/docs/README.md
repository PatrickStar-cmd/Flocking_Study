## 模型和方法

- N20由3领航者、17跟随者组成；每架15条固定有向观测，屏蔽跟随者观察领航者的51条边。
- 领航者额外接收.32余弦目标方向输入，跟随者不读取任务指令。目标方向不是目标位置或强制领航轨迹。
- 7方法：Fresh、Drop、Drop-normalized、Hold、最近10次合法历史的Linear-trend、KF-mean、KF-uncertainty。
- 可见观测含标准差.01 rad噪声，Fresh同样含噪；所有方法新鲜项直接用观测。
- KF估计方位与方位角速度，q=R=1e-4；缺测期间无观测更新；门控与原协议一致。
- dt=.3、800步；主遮挡第201—260步。时长扩展6/18/30模型时间；提前遮挡141—200步。
- N40/60分别6/9领航者，每个跟随者仍观察3领航者＋12跟随者；布局和分配图按v2，不能视为仅N变化的理论极限测试。

## Python复现

仿真使用Python，不是在MATLAB里执行。需要numpy、scipy、pandas、h5py、matplotlib、threadpoolctl。本机实际Python3.11.8、NumPy2.3.5；原协议参考版本Python3.12.14，差异已通过六方法参考数值对照检查。

在本目录执行：

```powershell
python run_experiments.py --name my_repeat --workers 6
python verify_results.py results/my_repeat
python analyze_results.py results/my_repeat
```

运行入口拒绝覆盖同名目录。仿真前执行算法/协议检查，并按运行前源码快照冻结。并行worker各自读取共享初态和完整噪声，BLAS每worker单线程。新名称可以复跑完整858条；本脚本不按结果选择子集。

## 代码对应关系

- reference_run_experiment.py：从YCwork取得的参考纯模型，SHA256与原协议一致；不执行其默认批量入口。
- leader_model.py：参考模型的完整记录扩展、Linear-trend以及N40/60拓扑/初始化。控制器不接收隐藏真值；传感层生成NaN观测。
- check_implementation.py：图、标量KF、真值隔离、门控、趋势外推、期望输入独立积分、六方法参考对照及T0。
- run_experiments.py：运行858条清单，保存源快照/共享随机输入、原始状态/日志/哈希。
- verify_results.py：独立从位置、速度、航向、逐边输入重新计算指标及校验全部运行。
- analyze_results.py：预定配对统计、工程诊断、七方法图表、全部种子尾段和轨迹。
- finalize_package.py：汇总验收、生成简要入口和包哈希。

## 原始文件结构

每条运行有CSV和HDF5。CSV是800行步级指标；HDF5是801帧位置、航向、神经场，800帧速度、社会输入场，800帧×选定边数的观测/注入/权重/KF状态/方差/年龄。另存遮挡前checkpoint和终态。

共享初态、固定神经网格、完整测量噪声按seed/N存inputs/*.npz，运行按文件哈希引用；大矩阵只保存一次。HDF5为float64和无损压缩，未删减时间段。

主分析的S_abs_error在每个分支自己的当前几何上构造无噪声oracle，不是所有候选读取同一Fresh轨迹的统一离线回放。提前遮挡复用Fresh物理数据时，冻结5邻居必须重新按第141步前状态计算，该处理已在分析中实现。
