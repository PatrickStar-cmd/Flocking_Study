# B-E2 实验 1–4 结果说明

运行模式：formal。

这是无遮挡探索性实验，不包含遮挡、KF、预测补偿或观测缺失。

- 实验1：比较 original 与 fixed-total 的输入强度。
- 实验2：扫描 k=2,4,8,12,19。
- 实验3：固定 k=8 和总输入，比较集中、随机、分散方位结构。
- 实验4：固定 k=8 和总输入，比较五种选邻策略。

主要指标：meanGO、meanLO、meanPairDistanceNorm、meanInputAmplitude、meanAngularCoverage、meanInputConcentration、socialUnionLccFraction 和 socialAlgebraicConnectivity。

先检查实验1的输入幅值是否符合设计，再解释实验2–4的群体指标。最终结论必须使用独立种子和冻结后的统计方案。
