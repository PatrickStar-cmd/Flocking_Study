# 首次早期宽窗：四方法追踪小规模实验（运行前固定）

日期2026-11-05。问题是在较早的首次遮挡中，KF是否改善Hold和Drop的追踪误差。

## 固定条件
- 12架：1领航者、11跟随者。初始位置、随机航向生成方式、神经场、观测和KF与上一轮相同。
- 5个未用于上一轮的新种子971001、971002、971003、971004、971005；不挑选结果。
- 每条轨迹仅一次遮挡，0基起点20或40，窗宽30或40步；总长120步，dt=0.3（模型时间单位）。
- 按第1次更新计，遮挡分别从第21或41次更新开始。最大末步为0基79，之后还有40步恢复。
- 主条件为S40D40；S20D30、S20D40、S40D30是预先固定的邻近条件。主条件选取基于旧探索结果，不作为独立随机抽取的场景。
- 目标沿用x=235+0.6t，y=200+4sin(2πt/24)。不研究其周期性，也不修改轨迹。
- 领航者独立追当前目标，速度上限1.5；跟随者没有目标直接输入。
- 每跟随者接收1领航边和6普通邻居边，权重幅值0.24和0.012；遮挡1领航边和3普通边。
- Fresh使用全部新鲜带噪声观测；Drop缺失边直接移除；Hold保持最后一次方位；KF以相对方位和变化率预测缺失观测。
- KF-mean，q=R=1e-4，max_age=120，max_variance=1。未遮挡时KF也直接使用新鲜观测。不修改旧参考代码。
- 共65条独立闭环轨迹：5条Fresh共享评分，60条处理轨迹，80个逻辑评分单元。

## 指标和判定
- 主评价为遮挡期间逐步平均的跟随者绝对角度误差和到当前目标的欧氏距离；先平均11架，再按时间，最后按种子配对。
- 角度用更新后的实际速度方向与同一时刻自身指向当前目标的方向之最短绝对夹角；不以质心代替逐机距离。
- 主差值KF-Hold、KF-Drop，负值表示KF更好；两指标分别报告。
- 同时保留遮挡最后一步、最后3步、前20步、恢复后20步、共同80步固定区间、全120步的结果。
- 每个种子的差值、均值、样本标准差、改善种子数全部报告。不把时间步或11架飞机当作独立样本。
- 不用跨不同窗宽的累计误差值直接判断优劣。n=5为探索性小规模实验，不宣称普遍有效或统计显著。
- 本实验不检验随机初向的因果作用；没有设置一致初向对照。
