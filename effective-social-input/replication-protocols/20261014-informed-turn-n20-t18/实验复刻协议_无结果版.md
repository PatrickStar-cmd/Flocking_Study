# 20对象转向与连续方位缺测实验复刻协议（无结果版）

- 协议版本：1.0；整理日期：2026-10-14。
- 实验标识：`informed-turn-N20-T18`。
- 用途：交给独立实现者复刻实验条件、生成原始数据和图表。
- 证据类型：三个既定开发种子的探索性复刻；这些种子不是未使用的确认性验证集。
- 本文只规定设计、算法、分析和软件检查，不提供已有曲线、观测结果、方法排名或预期优劣。

## 1. 范围与待检验问题

本实验采用异中心环形神经场模型，并增加三个对象专有的外部转向提示。20个对象均受社会输入影响，其中编号1–3接受外部提示，编号4–20不接受。本文将前者称为“提示对象/领航者”，后者称为“跟随者”。这是实验人为指定的角色，不是从运动结果中识别出来的角色。

本协议对应固定“3＋17”角色、每个对象15条输入的设置。它不是所有对象各观测其余19个对象、没有固定角色的同质全连接设置；也不包含“跨组遮挡与同数量桥接”条件。不要将两种设计混合复刻。

需要独立回答：

1. 全观测情况下，外部提示能否产生群体转向？
2. 在既定转向过程中的既定时刻，缺失指定方位观测是否改变运动响应？
3. 删除输入、补偿剩余输入幅值、保持最后方位、KF预测及带不确定性的KF输入之间有何差异？
4. 方位误差、社会输入误差与群体运动指标是否呈现一致或不同的变化？

不得以得到某种方法排序作为复刻成功条件。复刻应保留全部种子、全部时段和全部条件。

## 3. 固定观测图与遮挡图

以下对象编号采用1起始，程序数组可以采用0起始，但须明确转换。

定义 `selected[i,j] = True` 表示对象i使用对象j的方位输入，即信息方向是j→i。不得把矩阵行列的含义反过来。

- 对象1–3：每个对象选择另外两个提示对象，以及对象4–16，共15个目标。
- 对象4–20：每个对象选择对象1–3，以及其后12个跟随者；后12个按17个跟随者的编号环循环选择。
- 不选择自身；邻接关系在整个仿真中固定，不随距离重新选择。

对于跟随者环下标 `f=0,...,16`，对应对象编号 `i=f+4`，其另外12个跟随者目标为：

```text
4 + ((f + r) mod 17),  r = 1,...,12
```

全观测时有20×15＝300条有向观测边。

定义遮挡掩码：

```text
hidden[i,j] = selected[i,j] and (i in 4..20) and (j in 1..3)
```

因此指定缺测的是17×3＝51条有向观测边，占全部选定边的17%；对每个跟随者而言是其15条观测中的3条，即20%。这两个比例分母不同。

遮挡窗口内，除Fresh条件外：

- 上述51条观测缺失；其余249条观测继续正常产生。
- 每个跟随者有12条新鲜输入，每个提示对象有15条新鲜输入。
- 所有20个对象都继续运动，神经状态不重置，目标对象不删除，航向不额外随机跳变。
- 所有提示对象到跟随者群体的新鲜观测入口均被屏蔽；跟随者之间的观测保持。遮挡前获得的信息仍可存在于神经状态和缓存中。

这是按时序施加的方位缺测干预，不设置实体障碍物、有限视场、观测延迟或目标关联错误。

## 4. 初态与随机数生成

使用NumPy的 `Generator(PCG64(seed))`，每个种子单独初始化，建议串行运行。不得把种子数值直接用于另一种随机数算法后声称逐点复现。

### 4.1 初始位置与航向

三个提示对象的名义位置依次为：

```text
(492,492), (492,500), (492,508)
```

跟随者下标 `j=0,...,16`，对应对象编号 `j+4`，名义位置为：

```text
x = 480 - 8 * floor(j/4)
y = 500 + 8 * ((j mod 4) - 1.5)
```

随后对20个对象的两个坐标分别加入独立 `N(0,0.4²)` 扰动。初始航向 `phi_i[0]` 独立取自 `N(0,0.03²)`，中心为世界坐标+x方向。

这是事先构造的近似有序初态，不使用仿真后筛选的成功终点，不按GO或其他结果挑选初态。

### 4.2 固定神经元方向网格与初始神经场

神经元编号 `m=0,...,99`：

```text
alpha[i,m] = (2*pi*m/100 + phi_i[0]) mod (2*pi)
u[m,i,0] = 0.1*cos(alpha[i,m] - phi_i[0]) + epsilon_u[m,i]
epsilon_u ~ N(0,0.001²)
```

`alpha` 是固定的世界坐标方向网格；运动时不随当前航向旋转。

### 4.3 保持随机数调用顺序

同一种子必须按以下顺序整批抽样，数组使用NumPy默认C顺序：

1. 位置扰动：`rng.normal(0,0.4,(20,2))`。
2. 初始航向：`rng.normal(0,0.03,20)`。
3. 神经场扰动：`rng.normal(0,0.001,(100,20))`。
4. 全程测量噪声：`rng.normal(0,0.01,(800,20,20))`。

第4项包含自身和未选边对应的随机数，即使这些元素不使用也须生成。不得根据是否遮挡、是否选中或采用哪个方法而减少抽样。

同一种子的所有条件共享上述初态、固定网格与完整噪声数组；每个条件复制初始状态后独立演化。不要让方法运行顺序改变随机数。

## 5. 神经场、社会输入与运动更新

定义角度环绕：

```text
wrap(x) = ((x + pi) mod (2*pi)) - pi
```

### 5.1 周期空间几何与观测

从对象i指向对象j的最短周期位移为：

```text
r_ij = p_j - p_i
r_ij = r_ij - 1000*round(r_ij/1000)
theta_ij = atan2(r_ij.y,r_ij.x) mod (2*pi)
d_ij = norm(r_ij)
```

`round`按NumPy最近偶数舍入约定。新鲜方位观测：

```text
y_ij[n] = (theta_ij[n] + noise[n,i,j]) mod (2*pi)
```

无新鲜观测的位置传入 `NaN`，同时传入独立的布尔新鲜掩码。控制模块不得从另一个参数、全局变量或几何缓存读取被隐藏的真实方位、位置、速度或距离。

### 5.2 环形连接与社会输入核

令 `a_m=2*pi*m/100`，神经元间角距离：

```text
delta_mn = abs(wrap(a_m-a_n))
W[m,n] = cos(pi * sqrt(delta_mn/pi))
```

保留对角元素，使用下式中的 `1/100` 归一化，不另加全局抑制项。

普通方位输入核为未归一化的周期角距离高斯核：

```text
K_sigma(x) = exp(-0.5*(wrap(x)/0.4)²)
I_social[m,i] = sum_j w_ij*K_sigma(alpha[i,m]-center_ij)
```

基础权重 `w_ij=0.012`。删除、幅值归一化、预测和不确定性处理见第7–8节。距离权重始终为1，没有距离衰减，也不从距离真值生成控制量。

### 5.3 转向任务与同步更新

用0起始步编号 `n=0,...,799`，在本步使用的目标方向为：

```text
elapsed = max(0,(n-100+1)*0.3)
phi_cmd[n] = min(pi/4,0.025*elapsed)
```

只有对象1–3接受：

```text
I_task[m,i] = 0.32*cos(alpha[i,m]-phi_cmd[n]),  i=1,2,3
I_task[m,i] = 0,                              i=4,...,20
```

这是带正负值的余弦提示，勿替换为非负高斯提示。它只加入神经场，不直接设定对象速度或航向，也不提供给跟随者控制器或其KF。

先用本步开始时的全部状态计算输入，再同步执行：

```text
u[:,i,n+1] = u[:,i,n] + 0.3 * (
    -u[:,i,n] + W @ tanh(1000*u[:,i,n])/100
    + I_social[:,i,n] + I_task[:,i,n]
)
z[m,i] = max(tanh(1000*u[m,i,n+1]),0)
v_i[n] = 0.05 * [sum_m z[m,i]*cos(alpha[i,m]),
                 sum_m z[m,i]*sin(alpha[i,m])]
p_i[n+1] = (p_i[n] + 0.3*v_i[n]) mod 1000
```

若速度模长大于 `1e-12`，用 `atan2(v_y,v_x) mod 2*pi` 更新航向；否则保留上一航向，并将GO/LO使用的单位速度向量置零。不要依次更新对象后立即让后续对象读取其新位置。

## 7. 六个主条件

| 条件ID | 图例 | 缺测期间的社会输入规则 |
|---|---|---|
| `fresh` | Fresh | 始终使用全部15条当前含噪观测，不应用遮挡掩码 |
| `drop` | Drop | 只注入新鲜观测，缺测项权重置零；保留神经场记忆 |
| `drop-normalized` | Drop normalized | 只注入新鲜观测，每个对象的剩余权重乘15/当前新鲜条数 |
| `hold` | Hold | 新鲜项用当前含噪观测，缺测项用最后一次含噪观测 |
| `kf-mean` | KF mean | 新鲜项用当前含噪观测，缺测项用KF预测方位均值 |
| `kf-uncertainty` | KF uncertainty | 新鲜项用当前含噪观测，缺测项用KF方位分布对应的期望输入核 |

`drop-normalized`中，遮挡时跟随者的每条剩余输入幅值为 `0.012*15/12=0.015`；提示对象仍为0.012。它保持系数总和，不保持输入核的空间分布或神经场峰值。仅将其作为幅值因素对照。

Hold只使用缓存的观测方位，不使用遮挡前的真方位。所有KF条件在有新鲜观测时仍直接用观测驱动神经场，不以滤波均值替代当前观测。滤波器同时更新，以备后续缺测使用。

除Fresh外，各方法按第6节应用同一个缺测窗口；缺测窗口之外统一使用全部当前观测。

## 8. KF、缓存和不确定性输入

### 8.1 每条有向边独立滤波

状态为方位与方位角速度：

```text
x = [theta,omega]^T
F = [[1,0.3],[0,1]]
H = [1,0]
Q = 0.0001 * [[0.3³/3,0.3²/2],[0.3²/2,0.3]]
R = 0.0001
```

这是方位状态估计，不估计二维邻居位置。`q`是构造Q的强度参数，不是方位过程噪声标准差。

某条边首次有观测时直接初始化：

```text
x = [y,0]^T
P = diag([R,1])
last = y
age = 0
```

首次初始化前不产生缓存输入。后续每步先对已经初始化的边预测：

```text
x_minus = F @ x
P_minus = F @ P @ F.T + Q
age = age + 0.3
```

若本步有新鲜观测，再更新：

```text
innovation = wrap(y - x_minus[0])
gain = P_minus[:,0] / (P_minus[0,0] + R)
x = x_minus + gain*innovation
J = eye(2) - outer(gain,H)
P = J @ P_minus @ J.T + R*outer(gain,gain)
last = y
age = 0
```

无观测时保持预测值及预测协方差。更新后将状态中的方位分量取模到[0,2π)，角速度分量不取模。协方差用Joseph形式更新；不得先将创新当作普通线性角差。

每条缺测输入的激活规则：

- Hold：已初始化且 `age <= 120`。
- 两种KF：已初始化、`age <= 120`，且 `P[0,0] <= 1`。
- 不满足规则的项权重置零，并保存激活/剔除计数；不要假定整个缺测窗口内预测项始终激活。
- 新鲜项按本步观测更新和激活；恢复观测时不清空原滤波器，也不重新构造神经场。

为了诊断一致性，可以在所有条件维护相同的影子KF；它不能改变Drop或Hold各自的注入规则。

### 8.2 KF uncertainty的离散卷积

对缺测且激活的边，用KF均值 `mu=x[0]`、方位方差 `V=P[0,0]`。在对象i的100点方向网格上构造：

```text
g[m] = exp(-0.5*(wrap(alpha[i,m]-mu)/0.4)²)
freq = np.fft.fftfreq(100)*100
g_uncertain = real(ifft(fft(g)*exp(-0.5*V*freq²)))
g_uncertain = maximum(g_uncertain,0)
```

再以基础权重0.012加入社会神经场。新鲜项的V按0处理。这里是圆周上的不确定性卷积，不额外除以核积分或改变基础权重。

## 9. 六项主图指标

### 9.1 GO

用本步更新后的速度定义单位向量 `e_i=v_i/||v_i||`，静止对象置零：

```text
GO = norm(sum_i e_i)/20
```

统计全部20个对象。

### 9.2 LO

用步末位置的周期距离，为每个对象找当前最近5个其他对象；加上自身组成6个对象的局部集合 `B_i`：

```text
LO = mean_i(norm(sum_{j in B_i} e_j)/6)
```

局部邻居从全部19个其他对象中选，不受固定15条输入图限制；每步重新选择。用 `np.argsort(distance_after,axis=1)[:,:6]` 时距离矩阵应包含对角零元素。

### 9.3 冻结5邻居平均距离

在第201步更新之前，即绝对时间60的状态，为每个对象从其余19个对象中选出最近5个对象，记录身份集合 `F_i`。之后不重新选邻：

```text
D_fixed5[n] = mean_{i=1..20, j in F_i} d_ij[n+1]
```

平均100条有向距离，使用周期距离。此指标在遮挡前填NaN；它不是当前最近邻距离，也不是相对于Fresh的距离偏差。没有除以区域边长。

### 9.4 跟随者目标转向误差

用步末实际航向与本步目标方向：

```text
E_turn[n] = mean_{i=4..20} abs(wrap(phi_i[n+1]-phi_cmd[n])) * 180/pi
```

这是17个个体绝对角差的平均，不是群体平均航向的角差，也不是相对于实际提示对象平均航向的误差。

### 9.5 社会输入经验指标S

此指标在本步更新前，以本步注入的输入及本步开始时的实际航向计算。令：

```text
f(x) = exp(cos(x)-1)
S_i = sum_j w_ij*f(center_ij-phi_i[n])
S = mean_{i=4..20} S_i
```

注意，经验指标的f与神经场高斯核不是同一个函数。权重采用实际注入权重，包括删除、归一化及激活门控后的权重。外部转向提示不计入S。

对于KF uncertainty的缺测激活项，将 `f(mu-phi_i)` 替换为其方位分布期望。与离散实现一致的计算为：

```text
grid = arange(100)*2*pi/100
coef = real(fft(exp(cos(grid)-1))/100)
d = mu - phi_i[n]
factor = coef[0] + 2*sum_{h=1..23} (
    coef[h]*exp(-0.5*V*h²)*cos(h*d)
)
```

### 9.6 同状态社会输入绝对误差

评估器对每个条件自己的当前状态，用无噪声真方位、全部15条选定边和基础权重构造完整参照：

```text
S_oracle_i = 0.012*sum_{j:selected[i,j]} exp(cos(theta_ij[n]-phi_i[n])-1)
S_abs_error = mean_{i=4..20} abs(S_i-S_oracle_i)
```

不能先对S取群体平均再计算绝对差；也不能统一使用Fresh的几何作为所有方法的同状态参照。该参照仅用于离线评价，不提供给控制器。

GO、LO、距离和转向误差是步末指标；S及其误差是步初输入诊断。它们沿用同一行的步末时间标签，绘图和说明中必须保留这一约定。

## 10. 配对分析、补充诊断与有效性检查

### 10.1 固定分析窗口

- 遮挡窗口：第201–260步，共60步。
- 恢复早期窗口：第261–360步，共100步。
- 终末方向窗口：最后30步，即第771–800步。
- 保留完整800步曲线，不能仅保存上述窗口。

每个指标先在每个种子内计算窗口均值，再汇总三个种子。对于方法m相对Fresh的配对差，采用同种子、同时间行对齐。距离“有符号差”与“绝对偏差”分别保存，不能混用。

可计算：

```text
turn_delta_s = mean_event(E_turn_drop - E_turn_fresh)
distance_abs_dev_s,m = mean_post(abs(D_fixed5_m-D_fixed5_fresh))
method_delta_s,m,b = metric_s,m - metric_s,b
```

每个配对差须保留三个种子的原值。三个开发种子主要用于描述性分析；种子范围不能命名为置信区间。若补充bootstrap，以种子为重采样单位并明确其探索性，不把每个时间步当作独立样本。

### 10.2 转向与遮挡的工程检查规则

以下规则固定用于诊断，不是物理定律或普适门槛，不得为达到通过率而调整：

1. 在Fresh终末30步，提示对象的平均目标误差不大于10°，跟随者平均目标误差不大于15°，跟随者圆周平均方向的时间均值不小于30°。
2. 第1项同时满足时，再检查Drop相对Fresh在遮挡窗口内的平均跟随者目标误差增量是否不小于3°。
3. 跟随者圆周平均方向逐步计算为 `angle(mean(exp(1j*phi_followers)))`，转为度后按原实现取上述窗口的算术均值。同步保存圆周合矢量长度，遇到方向均值不适定或跨±180°时单独标注，不静默换算法。
4. 逐种子报告各项数值和判定；无论判定如何，六个条件均保留，不删除种子，不选择另一个遮挡起点。

### 10.3 无转向对照

为辨别缺测影响与外部转向任务的关系，另外运行每个种子的 `straight-fresh` 和 `straight-drop`，共6个控制运行。仅将目标方向改为始终0°，保留0.32余弦提示、初态、噪声、图和缺测时序。

对比：

```text
turn_specific_delta_s =
    mean_event(E_turn_drop - E_turn_fresh)
    - mean_event(E_straight_drop - E_straight_fresh)
```

此项独立保存，不将其与六条件主图混为一条曲线。

### 10.4 补充诊断字段

建议保存以下诊断，以便识别指标之间的差异：

- 每步提示对象与跟随者各自的目标误差、圆周平均方向和合矢量长度。
- 每步平均速度、静止对象比例、最小周期距离、当前最近邻距离、提示对象—跟随者平均距离。
- 每步新鲜边数、激活边数、被遮挡边中的激活数及门控原因。
- 每条缺测边的最后观测、当前注入方位、KF状态、方位方差和输入年龄。
- 活跃缺测边的方位绝对误差：对 `abs(wrap(center-theta_true))*180/pi` 平均；无激活项时为NaN，不填0。
- 如计算KF名义95%覆盖率，用 `abs(wrap(mu-theta_true)) <= 1.96*sqrt(V)`；同时报告全部缺测边和门控后的口径，不能仅报筛选后的误差。
- 社会系数总和 `A_i=sum_j w_ij`、经验方向因子 `C_i=S_i/A_i`；A为0时C置0。

4. **隐藏真值隔离**：固定控制器状态、新鲜观测及掩码，改变评估器持有的隐藏真方位，控制模块输出应不变；评估误差可以变化。
