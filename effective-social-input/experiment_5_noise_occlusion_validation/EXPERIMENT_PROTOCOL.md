# 实验协议

## 研究问题

在多次短时遮挡下，提高方位观测噪声是否会扩大 KF-mean 相对 Hold 的跟随者目标方向追踪优势？

## 固定实验条件

- `N=30`，`L=6`，`24`名跟随者；每机最多观测15条邻居边。
- 每个跟随者每个遮挡窗口隐藏9条边。主要遮挡掩码隐藏全部6条领航者边，并补足3条跟随者邻居边。遮挡期间每个跟随者保留6条新鲜观测。
- 三个遮挡窗口为 `[180,200)`、`[300,320)`、`[420,440)`；每次20步，窗口之间有100步恢复期。
- 方法：Drop、Hold、KF-mean；Fresh为无遮挡参考。
- 20个随机种子。相同种子在所有方法、两档噪声下共用相同初态、角色、拓扑及标准正态噪声张量。

## 噪声条件

- 低噪声：`σ=0.01 rad`，KF观测方差 `R=0.0001 rad²`。
- 中等噪声：`σ=0.035 rad`，KF观测方差 `R=0.001225 rad²`。
- 过程噪声 `q`、动力学、目标路线、遮挡时刻与遮挡边数固定。
- 观测噪声使用相同标准正态样本 `Z`，分别为 `0.01 Z` 与 `0.035 Z`。

## 指标和统计

主指标为三次遮挡步合并后的跟随者目标方向误差，单位为度，数值越小越好。每档噪声的算法差定义为 `Δσ = E_track(KF-mean) − E_track(Hold)`，负数表示KF改善追踪。

主要假设检验使用配对交互差：`Δ_medium − Δ_low`。该差为负且区间不跨0，才支持“中等噪声扩大KF相对Hold优势”。另报告各遮挡窗口、`GO_all`、方位预测误差、社会输入误差、平均群体距离和最小间距。统计独立单位为种子，报告配对均值差、95% t区间、bootstrap区间和p值。

## 解释边界

这是小规模验证实验，20个种子用于检验思路，不代表最终论文样本量。KF必须与观测噪声匹配R。若交互差区间包含0，则现有结果不能确认噪声放大KF优势；若KF优于Hold，也不能据此声称KF优于Drop。
