# 实验_5：中等观测噪声与多次短遮挡验证

本目录是从本地 `10.19周/实验_5_噪声_遮挡验证实验` 整理出的轻量复现包，包含运行代码、实验协议、结果摘要、统计表、图表、运行清单和完整性检查。逐次仿真CSV与配对随机输入张量体积较大，保留在本地，不纳入仓库；使用固定种子可重新生成。Python字节码缓存也未上传。

这是一个小规模验证实验，固定实验_4的追踪场景，只比较低噪声与中等方位观测噪声是否改变 KF 相对 Hold 的追踪误差。实验固定 `N=30`、`L=6`、`K=15`，每个跟随者每次隐藏9条观测边，并沿用三个各20步、间隔100步的遮挡窗口。主遮挡条件隐藏全部领航者边并补足3条普通邻居边。

噪声标准差为 `0.01 rad` 和 `0.035 rad`。同种子复用同一个标准正态观测噪声张量，只乘不同标准差；两档噪声下初始位置、航向、拓扑和角色分配相同。KF 的 `R` 分别设为 `0.01^2` 和 `0.035^2`，过程噪声 `q` 固定。

## 查看已有结果

先看 `results/formal_v1/RESULTS_SUMMARY.md`。`results/formal_v1/analysis/` 保存统计表，`figures/` 保存图表，`RUN_MANIFEST.csv` 保存逐次运行的预期路径、行数和原始SHA-256。`checks/verification.json`记录完整性检查；本机原始批次160/160次运行通过。

## 复现

安装 Python 依赖：

```powershell
python -m pip install numpy pandas scipy matplotlib threadpoolctl
```

本仓库版本不含逐次运行CSV与输入张量，因此不能直接从仓库副本重算统计。若要从头重跑仿真并重建完整结果，请将本目录中的四个根级 `.py` 文件及 Markdown 文档复制到一个新的空目录（不要复制 `results/`），然后在该空目录运行：

```powershell
python run_experiments.py --workers 6
python analyze_results.py
```

运行器按固定清单续跑中断任务，并拒绝混合不完整逐步结果。若需检查历史原始文件哈希，可将本地完整结果与 `RUN_MANIFEST.csv` 对照；仓库中保留的是这些文件的哈希记录，而不是大体积原始轨迹。

共20个配对种子、两档噪声、Drop/Hold/KF-mean及Fresh参考，合计160条运行。主指标为跟随者目标方向误差（角度，越小越好）；主要检验是三次遮挡合并后的噪声交互。GO、预测误差、社会输入误差和凝聚性作为辅助指标。
