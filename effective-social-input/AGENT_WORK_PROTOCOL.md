# Agent 工作必读协议

每次开始本项目工作前，先阅读本文件和 `RESEARCH_ROADMAP.md`，再读取当前结果目录的 `audit.json` 与最近的 README。所有 agent 共享同一目录，禁止用旧上下文假设文件状态。

## 不可违反的研究约束

1. 原始代码目录 `../allocentric-flocking-original` 只读，禁止修改。
2. 已有 CSV、MAT 和分析结果默认只读；新实验使用新文件名，不覆盖旧结果。
3. 任何阈值必须同时写明 N、神经参数、输入制度、选邻策略、观测模型、评价时间和成功定义。
4. 不得把 `k=7`、`k=10` 或其他点估计写成普适下限。
5. fixed-total 只用于机制拆分；不得称为自然传感器或生物控制律。
6. 只有方位观测时，不得宣称卡尔曼滤波恢复了二维邻居位置；必须说明状态和可观测性。
7. 时间平均指标不得称为持续成功、失效时间或恢复时间。
8. 先独立评估，再讨论阈值；同一批数据标定和评估必须明确标注为探索性。

## 每次工作的标准顺序

1. 检查当前 MATLAB 进程、结果文件更新时间、种子完整性和 git/worktree 状态。
2. 读取配置、仿真器、运行器和分析器中与任务相关的代码。
3. 写出本次工作的输入、输出、随机种子、是否修改源代码和验收标准。
4. 先运行 smoke test 或最小可复现实验，再运行长实验。
5. 将日志、参数快照、哈希和分析结果写入新的结果子目录。
6. 独立复算至少一项关键计数或汇总，检查重复记录和缺失种子。
7. 报告实际结果、统计限制和未完成事项；不以运行成功代替科学结论。

## 结果命名

- 原始仿真：`results/effective-input-<profile>.csv/.mat`
- 阶段分析：`results/<stage>-<date>/`
- 日志：同一分析目录或 results 根目录下的带时间戳 `.log`
- 元数据：`audit.json`，至少包含源文件 SHA256、参数、种子、软件版本和排除规则

## 统计最低要求

- 每个条件报告试验数、成功数、点估计和 95% 区间；
- 单项 GO、LO、凝聚结果与联合结果分开；
- 保序回归只能作为敏感性分析，不能创造新的观测证据；
- bootstrap 要说明重采样单位和是否重新标定；
- 不能把 Wilson 下界未达到 0.95 写成“失败”，应写成“尚未证明达到 0.95”；
- 发现非单调曲线时保留原始曲线，不能只展示平滑结果。

## 代码修改规则

- 修改前先发出简短进度说明；
- 使用 `apply_patch`，不使用 shell 重定向覆盖代码；
- 新增时间序列字段时保持旧 summary 字段兼容；
- 任何新随机过程必须记录 seed 和参数；
- 运行失败时保留日志和部分结果，禁止删除来掩盖失败；
- 完成后运行 smoke test、关键回归检查和独立统计复核。

## 三因素与距离权重约束

主研究因素固定为 `k`、邻居方位角结构和连续遮挡时间 `T`。距离相关权重是现实感知扩展，不得与原论文等权结果混写。

距离权重必须显式写成 `a(r)` 并记录其函数形式、尺度和来源。遮挡期间不能使用仿真的真实距离或真实方位更新输入；只能使用最后观测或滤波器的预测及其不确定性。只有方位观测时，状态必须是方位/角速度或经过可观测性论证的相对状态。

任何新实验都至少包含 `a(r)=1` 的等权对照；先单独扫描距离权重，再扫描 `T`，避免三个因素同时变化无法归因。远邻贡献较小是待检验假设，不是预先结论。
